# LangChain RAG Application with Gemini & Chroma

A Retrieval-Augmented Generation (RAG) pipeline built using **LangChain**, **Google Gemini**, **ChromaDB**, and **Sentence Transformers**.

## Features
- **Document Loading:** Web-based document ingestion.
- **Chunking:** Text splitting via `RecursiveCharacterTextSplitter`.
- **Vector Store:** Local vector database using `langchain-chroma`.
- **LLM Integration:** Powered by Google's `gemini-2.0-flash`.
- **Prompting:** Pulled dynamically from LangChain Hub.
